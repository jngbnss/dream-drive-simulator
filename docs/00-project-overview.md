# 00. 프로젝트 개요 — Dream Drive Simulator

## 1. 한 줄 정의

좋아하는 사람이 자신의 드림카(Mercedes-Benz GLC Coupé 참고 차량)를 **웹 브라우저에서 바로** 구경하고, 탑승하고, 서울 도심과 서킷을 달려볼 수 있는 인터랙티브 드라이빙 시뮬레이터.

## 2. 목표 분석

| 사용자 경험 | 핵심 요구 기술 | 담당 단계 |
|---|---|---|
| 외관 360도 구경 | 오빗 카메라, PBR 재질, 환경광(HDRI) | 03, 04 |
| 실내·운전석 관찰 | 실내 모델, 1인칭 카메라, 계기판 | 03, 04 |
| 직접 탑승해 주행 | 차량 물리(레이캐스트 차량), 입력 시스템 | 02 |
| 서울 도심 드라이브 | 절차적 도시 + OSM 일부 지역 | 05 |
| 서킷 고속 주행 | 서킷 트랙, 랩타임, 고속 안정성 | 05 |
| 엔진음·브레이크·조향·서스펜션 몰입감 | Web Audio, 차체 롤/피치, 카메라 흔들림 | 06 |
| 키보드·마우스, 향후 레이싱 휠 | 입력 추상화 + Gamepad API | 02, 03, 이후 확장 |
| **친구에게 주소만 주면 바로 체험** | 정적 웹 배포(GitHub Pages) + 자동 배포 | **01부터 지속** |

### 성공의 정의
"기술 데모"가 아니라 **링크 하나로 열어서 1분 안에 드림카에 앉아 볼 수 있는 경험**입니다. 그래서 다음을 최우선으로 둡니다.

1. 접근성: 설치 없이 링크 클릭 → 5초 이내 첫 화면
2. 첫 인상: 차량 외관이 예뻐 보이는 쇼룸 화면
3. 조작감: 물리적으로 그럴듯하고 운전이 재미있는 차량
4. 확장성: 맵·차량·입력 장치를 나중에 갈아끼울 수 있는 구조

## 3. 범위

### 포함
- 웹 브라우저(데스크톱 Chrome/Edge/Firefox/Safari 최신판) 실행
- GLC Coupé를 **참고한** 차량(공식 모델·로고 사용 안 함, 아래 법적 고려 참조)
- 서울 "스타일" 절차적 도심 + OSM 기반 실제 도로 일부 지역(선택 적용)
- 가상의 오리지널 레이싱 서킷
- 규칙 기반 교통, AI 기반 자연어 목적지·음성 가이드

### 제외 (현 시점)
- 모바일 터치 조작 최적화 (기본 동작만 보장, STEP 08에서 재검토)
- 멀티플레이어
- 서울 전역의 실제 지형·건물 재현
- 실제 차량 제조사 공식 데이터 기반의 정밀 동역학

## 4. 법적·라이선스 고려 (확인된 사실과 가정 구분)

| 항목 | 상태 | 내용 |
|---|---|---|
| Mercedes-Benz 상표·엠블럼 | **확인됨(일반 원칙)** | 상표와 엠블럼은 상표권 보호 대상. 공개 배포 시 엠블럼·로고는 넣지 않음 |
| 차량 외형 디자인 | **가정** | 디자인권이 문제될 수 있음. 비상업 팬 프로젝트라도 "GLC Coupé 참고(inspired)" 자체 제작 모델로 진행하고, 공식 명칭은 설명 문구에만 사용 |
| Sketchfab 등 외부 GLC 모델 | **미확인** | 모델마다 라이선스가 다르고, 대부분 상표 문제를 따로 해결하지 않음. 개별 확인 전에는 사용하지 않고, 개인 로컬 교체용(GLB 교체 기능)으로만 지원 |
| OpenStreetMap 데이터 | **확인됨** | ODbL 1.0. 출처 표기 필수("© OpenStreetMap contributors"), 파생 DB 공유 조건 있음 |
| 실제 서킷(인제 스피디움, KIC 등) | **가정** | 레이아웃 재현 시 권리 문제가 생길 수 있으므로 오리지널 가상 서킷을 제작 |

## 5. 확정된 기본 결정 (오피스아워 권장안 적용)

전체 결정 로그는 [`progress.md`](./progress.md)의 "결정 로그"에 있습니다.

- 웹 스택: **Vite + TypeScript + Three.js + Rapier**
- 배포: **GitHub Pages + GitHub Actions**, STEP 01부터 `main` 머지 시 자동 배포
  - 예상 주소: `https://jngbnss.github.io/dream-drive-simulator/`
- 차량: 자체 제작 "GLC Coupé 참고" 모델 + 외부 GLB 교체 기능
- 서울: 절차적 서울 스타일 도시 먼저, OSM 실제 도로는 소규모 지역에 단계 적용
- AI: 교통은 규칙 기반(IDM), AI는 **자연어 목적지 선택 + 음성 가이드**에 집중
