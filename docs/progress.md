## 5. 개선 기록 (문제 → 측정 → 원인 → 대안 비교 → 적용 → 재측정)

| 문제 | 측정 | 원인 | 적용 | 결과 |
|---|---|---|---|---|
| 최고속이 4단 175km/h에서 정체 | 시뮬 40초 추적 | 선형 감쇠 0.02가 고속에서 약 1.8kN 저항 | 감쇠 0, 공기저항 직접 계산 | 239km/h, 0-100 6.72→6.07초 |
| OSM 다운로드 504/500 | 타일별 로그 | 한강 멀티폴리곤 전체 형상 요청 | 6×3 타일 + 관계는 `out geom(bbox)` + 캐시 | 18타일 완료, 13.4MB |
| 도로가 안 보임 | 셰이더 로그 | GLSL 예약어 `half` | 변수명 변경 | 해결 |
| 물리 ms가 0으로 표시 | 오버레이 | 측정 초기화가 물리 스텝 뒤에 실행 | 루프에 `begin()` 훅 | 0.07~0.19ms |
| 쇼룸에서 R(후진) 표시 | 계기판 | 정지 브레이크 입력이 후진으로 해석 | 주차(P) 상태 추가 + 테스트 | 해결 |
| 모바일에서 차체 사라짐 | 모바일 에뮬레이션 | 느린 프레임에서 차체 롤 스프링 발산(NaN) | 1/120s 서브스텝 + 클램프 | 해결 |
| 차체 옆면 사선 줄무늬 | 근접 스크린샷 | earcut 긴 삼각형 법선 보간 | 변형 함수로 해석적 법선 | 개선 |
| 밖에서 실내가 훤히 보임 | 스크린샷 | 유리 불투명도 0.38 | 카메라 위치별 투명도(외부 0.78/실내 0.14) | 개선 |
