# Dream Drive Simulator

Mercedes-Benz GLC Coupé를 참고한 드림카를 웹 브라우저에서 구경하고, 탑승하고, 서울 도심과 서킷을 달려볼 수 있는 3D 드라이빙 시뮬레이터입니다.

> 현재 상태: **설계 단계** — 문서는 [`docs/`](./docs)에 있습니다. 진행 상황은 [`docs/progress.md`](./docs/progress.md)를 보세요.

- 바로 체험하기: `https://jngbnss.github.io/dream-drive-simulator/` (STEP 01 배포 후 활성화)
- 스택: Vite · TypeScript · Three.js · Rapier

본 프로젝트는 비공식 팬 프로젝트이며 Mercedes-Benz와 관련이 없습니다. 차량 모델은 자체 제작한 참고 모델입니다.
